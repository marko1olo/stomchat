## 📌 1. ОБЗОР И НАЗНАЧЕНИЕ ПРОЕКТА

**StomChat** — специализированный цифровой клинический консилиум и ассистент врача-стоматолога в Telegram.
Проект предназначен для:
- Анализа дентальных рентгенограмм (прицельные снимки, ОПТГ, срезы КЛКТ) и фотопротоколов через Gemini Multimodal Vision.
- Предоставления доказательных клинических протоколов (46 EBM протоколов: BOPT, адгезивная фиксация E.max, протокол ирригации NaOCl/EDTA, извлечение отломков инструментов, апексификация).
- Интеллектуального триажа дискуссий врачей, детекции токсичности и конфликтов с автоматическим EBM-арбитражем.
- Расчета дозировок местных анестетиков и антибиотиков с учетом соматического статуса по классификации ASA.
- Автоматической генерации ежедневных аналитических выжимок (Daily Panorama) и еженедельных дайджестов (Weekly Digest).
- Интерактивных клинических симуляторов и аккредитационных квизов для врачей.

## ⚡ 3. АРХИТЕКТУРА И ПАЙПЛАЙН ОБРАБОТКИ СООБЩЕНИЙ

Пайплайн входящего события проходит строгий многоуровневый фильтр:

```text
[Telegram Event (Новое сообщение / Реплай / Фото)]
                        │
                        ▼
            [1. TG Safety & Anti-Flood]
       (Проверка кулдаунов, дедупликация, rate-limit)
                        │
                        ▼
              [2. Пре-триаж (Triage)]
      (Отсечение спама, бытового шума, проверка темы)
           ├── Личные сообщения (PM) ──────────► [PM Router]
           ├── Сообщение с фото/снимком ──────► [Vision Pipeline]
           ├── Конфликт/спор в чате ──────────► [Referee Arbitrage]
           └── Упоминание / прямой вопрос ─────► [Clinical Chat Core]
                        │
                        ▼
       [3. Заземление на знания (Red-Team RAG)]
   - Нормализация составных терминов (e.max -> emax, cad/cam -> cadcam)
   - Двустороннее раскрытие синонимов (DENTAL_SYNONYMS)
   - Поиск в stomat_bot.db.clinical_protocols (46 EBM стандартов)
   - Поиск в stomat_wiki.distilled_facts (12.7k фактов)
   - Поиск в stomat_archive (если context_type != 'vision')
   - Инквизиционный фильтр шума (отсечение неклинических совпадений)
   - Authority Boost (+20 для золотых стандартов EBM)
                        │
                        ▼
          [4. Когнитивная матрица (Master Core)]
     (Инъекция клинических правил, запрет сикофантства,
      требование первопринципов, презумпция артефакта)
                        │
                        ▼
           [5. Каскад LLM (Gemini Cascade)]
        (Gemini 2.5 Pro / Flash -> Flash Lite -> Llama)
                        │
                        ▼
     [6. Пост-генерационный рецензент (Quality Gate)]
    (Проверка на галлюцинации, передозировки, риски,
     при браке -> Safe Conservative Fallback)
                        │
                        ▼
           [7. Доставка ответа врачу]
     (HTML-форматирование, чистка маркеров, safe typing)
```

## 🗄️ 4. СПРАВОЧНИК ПО БАЗАМ ДАННЫХ

### 4.1. `stomat_wiki.db` (База Знаний)
- **Таблица `distilled_facts` (12 778 записей):**
  - `id`: Первичный ключ.
  - `category_code`: Иерархический код темы (L1.L2.L3, например, `1.1.1` — Эндодонтия/Доступ/МБ2).
  - `content`: Дистиллированная клиническая суть (протокол, дозировка, рекомендация).
  - `source_ids`: Ссылки на исходные сообщения врачей.
  - `confidence`: Оценка достоверности (1-5).
  - `content_hash`: Уникальный MD5-хэш для предотвращения дубликатов.

### 4.2. `stomat_bot.db` (Основная оперативная база)
- **Таблица `clinical_protocols` (46 записей):**
  - Золотые стандарты доказательной стоматологии (BOPT, E.max, NaOCl+EDTA, MTA, дебондинг, All-on-X).
  - Поля: `title`, `category`, `indication`, `contraindications`, `steps_json`, `materials`, `key_nuances`, `author_doctor`.
- **Таблица `messages` (167 000+ записей):**
  - История переписки сообщества с разметкой медиа (`has_media`, `media_description`, `media_type`).
- **Таблицы `user_memories` и `user_profiles`:**
  - Клинические портреты врачей, специализация, стиль общения (/style), история консультаций.
- **Таблицы `daily_polls` и `poll_votes`:**
  - Опросы, квизы, статистика голосования, разборы кейсов.

### 4.3. `stomat_archive.db` (Клинический исторический архив)
- **Таблица `archive_messages` (117 847 записей):**
  - Полный архив реплик специалистов с мультимодальными текстовыми описаниями снимков (`vision_description`).

## 🚀 5. РУКОВОДСТВО ПО ЭКСПЛУАТАЦИИ

### 5.1. Запуск бота
```powershell
# Запуск в фоновом режиме с принудительной кодировкой UTF-8:
python -X utf8 -u main.py
```

### 5.2. Тестирование
```powershell
# Запуск регрессионных тестов качества RAG:
$env:PYTHONPATH="."
python tests/test_rag_quality.py

# Запуск полного тестового пакета:
pytest tests/ -v
```

### 5.3. Перезапуск и Failover
- При миграции на микро-VPS или локальную машину соблюдать инвариант **Zero Split-Brain**: перед запуском на новом узле останавливать службу на предыдущем (`systemctl stop stomchat`).
- Копирование базы выполнять строго после `PRAGMA wal_checkpoint(TRUNCATE);` для предотвращения повреждения транзакций.
