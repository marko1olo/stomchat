Engineered for Clinical Chat Intelligence

Source-backed modules for Telegram workflows, optional media preparation, provider routing, lookup, storage, and digest delivery.

01

Telethon message workflows

assistant.py contains Telegram-facing handlers for private, group, mention, media, and digest-oriented flows. Runtime access still depends on the local Telegram configuration.

02

Media preparation routes

visionproc.py uses OpenCV and Pillow for video-frame extraction and image resizing. Whether a media item is analyzed depends on configured providers and the runtime path that receives it.

03

Lookup with source links

Configured Tavily and DDGS routes can retrieve web results for a request. Search output is context for professional review, not automatic clinical verification or medical advice.

04

Digest delivery

summarizer.py builds daily and weekly summary flows and can use the Telegraph publishing adapter when its local token and delivery configuration are available.

05

Provider cascade safeguards

gemini_client.py selects configured Gemini and Groq providers, persists hashed key cooldowns, retries retryable failures, and temporarily removes unavailable models from a cascade.

06

Async local storage and helpers

The project declares aiosqlite alongside dental vocabulary and text-processing helpers. Local data, credentials, and session material remain outside the public Pages surface.
