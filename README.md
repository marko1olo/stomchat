## 🌟 Capabilities

- **Automated Clinical Symptom Triage:** Pre-visit patient questionnaire and acute pain urgency classification using deterministic medical protocols.
- **RAG Knowledge Base:** Fast retrieval-augmented generation over clinical practice guidelines and contraindication databases.
- **WebSocket Gateway:** Low-latency bi-directional messaging with doctor takeover notifications.
